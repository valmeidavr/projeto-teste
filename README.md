# Currículo — Landing Page

Landing page profissional de currículo de programador, com tema claro/escuro, seção de habilidades com barras animadas, experiência, projetos e contato.

**Site:** https://valmeidavr.github.io/projeto-teste/

## Como usar

Abra `index.html` no navegador — não há build nem dependências.
Edite nome, contatos, experiências e níveis de habilidade (`data-level`, de 0 a 100) direto no `index.html`.

## Tecnologias

HTML5, CSS3 e JavaScript puro.
